# Detective

Детективная игра-допрос с ИИ. Игрок — следователь: допрашивает подозреваемых, предъявляет улики, ловит их на противоречиях и в конце называет убийцу, мотив и способ.

Персонажей играет языковая модель. Что персонаж может рассказать, решает не модель, а правила игры в коде: факты открываются давлением, уликами и пойманной ложью. Поэтому каждое дело честное и решаемое.

- **Движок:** Godot 4.7, GDScript
- **Платформы:** Android и ПК
- **ИИ:** Google Gemini через облачный API (свой ключ игрока, бесплатный уровень)
- **Статус:** проектирование. Первый прототип — текстовый; голос и 3D — следующие этапы.

## Дела и инструменты

- `cases/` — дела в JSON. Файлы `*_NOTES.md` и сами JSON содержат разгадку: не открывайте их, если хотите играть.
- `tools/validate_case.py` — проверка дела по правилам диздока и симуляция темпа:
  ```
  python3 tools/validate_case.py cases/<дело>.json --simulate 15
  ```

## Ключ API

Ключ Gemini берётся в [Google AI Studio](https://aistudio.google.com) и вводится в настройках игры. В репозиторий ключ не коммитится (см. `.gitignore`, `config/config.example.cfg`).
