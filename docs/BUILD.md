# Сборка

Игра собирается в GitHub Actions. Отладочный keystore создаётся внутри задачи и в репозиторий не попадает. Ключ Gemini, `config/dev.cfg` и `user://` в пакет не входят.

## Скачать готовую сборку

1. Откройте вкладку Actions репозитория и workflow «Сборка Android и Windows».
2. Выберите зелёный запуск (после слияния в `main` или ручной запуск).
3. Внизу страницы, в Artifacts, скачайте `detective-builds`.
4. Внутри архива: `Detective.apk` и `Detective-windows.zip`.

Ручной запуск: Actions → «Сборка Android и Windows» → Run workflow.

Если поставлен тег `v*`, те же файлы появляются в Releases.

## Планшет Android

1. Скачайте `Detective.apk` на планшет.
2. Разрешите установку из неизвестных источников для браузера или файлового менеджера, которым открываете apk.
3. Откройте apk и подтвердите установку. Архитектура — только arm64-v8a. Ориентация экрана — сенсор, альбом и портрет.
4. Запустите «Детектив».

## Windows

1. Распакуйте `Detective-windows.zip`. Рядом должны лежать `Detective.exe` и `Detective.pck`.
2. Запустите `Detective.exe`.
3. Если SmartScreen пишет, что издатель неизвестен: «Подробнее» → «Выполнить в любом случае». Сборка подписана только отладочным ключом Android; у exe подписи нет.

Если окно не открывается, запустите `Detective.console.exe` из того же каталога: он печатает ошибку Godot.

## Ключ Gemini

1. В игре откройте «Настройки».
2. Вставьте ключ в поле «Ключ Gemini API». Он хранится только в `user://config.cfg` на устройстве.
3. Нажмите «Проверить связь». Должно появиться «Связь есть.» Ключ на экран и в журнал не выводится.
4. «Сохранить», затем «Новое дело».

Без ключа живой допрос не стартует. Переключатель «Офлайн-отладка» обходится без сети и без ключа.

## Что не попадает в пакет

`cases/*.json` входит. Не входят `config/` (включая `dev.cfg`), `docs/`, `tools/`, `tests/`, `.github/` и файлы `*.md`.

## Локально

Нужны Godot 4.7.2, шаблоны экспорта той же версии, JDK 17 и Android SDK с `platform-tools` и `build-tools`. Пути JDK и SDK прописываются в редакторе: Export → Android. Keystore для отладки создайте сами и не коммитьте. Пресеты: `export_presets.cfg`, имена `Android` и `Windows Desktop`.
